How it works

People: each face is turned into 128 numbers (a face descriptor) by a neural network. Faces with close numbers are the same person.

Characters: an anime face detector finds drawn faces, and a second network (DINOv2) turns each one into 384 numbers that describe its look, so the same character is grouped together.

Things: an object detector (CenterNet) recognizes 80 kinds of everyday objects.

Videos: about one frame per second is checked (up to 90 frames per video), and the best view of each face is kept with its time, so you can jump straight to it.
